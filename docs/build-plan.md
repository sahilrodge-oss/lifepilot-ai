# LifePilot AI Build Plan

## Day 1: Understand And Narrow

- Position LifePilot AI as a Deadline Emergency Assistant.
- Define the user pain: deadline overload and urgent task confusion.
- Keep the MVP focused on deciding what to do first.
- Confirm the Google stack: Google AI Studio, Gemini API, Firebase Auth, Firestore, Firebase Hosting.

## Days 2-3: Build The Core

- Firebase Auth with email/password and Google Sign-In.
- Firestore collections: `users`, `tasks`, `goals`, `habits`, `aiPlans`.
- Add task form and dashboard metrics.
- Gemini AI plan generation with priority, risk, breakdown, schedule, reminder, and coaching.

## Days 4-5: Improve The Experience

- Emergency Mode survival plan.
- Role-Based Mode for students, professionals, entrepreneurs, freelancers, creators, and general users.
- Goals and habits context.
- Loading, empty, and error states.

## Day 6: Package The Demo

- Add five demo tasks.
- Record a backup walkthrough.
- Capture dashboard, AI planner, task form, and profile screenshots.
- Prepare Google Doc report.

## Day 7: Submit

- Run the full demo from a fresh browser.
- Confirm Firebase Hosting live link works publicly.
- Submit live app link, GitHub repository link, and Google Doc report link.
