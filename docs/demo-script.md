# Demo Script

Use this order for screenshots or a short demo video.

## 1. Login

Show Firebase Auth:

- Email/password login
- Google Sign-In button

Say:

```text
LifePilot AI uses Firebase Authentication for secure login and Google Sign-In.
```

## 2. Dashboard

Show:

- Total tasks
- Completed tasks
- Pending tasks
- High-risk tasks
- Productivity score
- Emergency alerts
- Google Calendar status

Say:

```text
The dashboard gives a quick view of deadline pressure, pending work, high-risk tasks, and productivity score.
```

## 3. Add Task

Add these five tasks:

```text
Submit assignment tomorrow
Prepare office report by Friday
Follow up with client today
Deliver freelance project in 2 days
Pay electricity bill tonight
```

Say:

```text
Each task stores title, description, deadline, estimated time, importance, category, and status in Firestore.
```

## 4. Voice Task Input

Use this command:

```text
Remind me to submit my project report tomorrow at 6 PM. It will take 3 hours and it is very important.
```

Click:

```text
Parse with Gemini
```

Say:

```text
Gemini extracts structured task data from a natural voice command and auto-fills the task form.
```

## 5. AI Planner

Click AI Planner and generate a plan.

Show:

- Priority ranking
- Deadline risk
- Task breakdown
- Today's plan
- Emergency Mode
- Productivity coach message

Say:

```text
Gemini works as the core AI decision engine. It tells the user what to start now, what is risky, and how to finish on time.
```

## 6. Google Calendar

Click:

```text
Connect Google Calendar
```

Then click:

```text
Add to Google Calendar
```

Say:

```text
LifePilot AI can turn a deadline task into a Google Calendar event with reminders.
```

## 7. Completion Update

Mark one task complete.

Say:

```text
After completing a task, the dashboard updates task metrics and productivity score.
```
