# Idea Selection

Use this when the two official problem statements are released.

Score each option from 1 to 5.

| Criteria | Problem 1 | Problem 2 |
| --- | ---: | ---: |
| User pain is easy to understand |  |  |
| MVP can be built in 7 days |  |  |
| Demo can show a clear before and after |  |  |
| Data or workflow is accessible |  |  |
| AI improves the product, not just the pitch |  |  |
| You can explain the impact simply |  |  |

## Pick The Problem That Wins On

1. Fastest path to a working prototype.
2. Clearest live demo.
3. Strongest user story.

Avoid ideas that need too many integrations, unavailable datasets, or heavy backend complexity before the product becomes useful.
